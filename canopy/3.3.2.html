Field Craft

Not every map needs QGIS and a shapefile pipeline. Web mapping tools like Carto let you go from a spreadsheet with location data to a shareable, embeddable interactive map without writing code — the right choice for most publication-ready story maps.

Carto Basics

Carto is a cloud-based mapping platform built around a simple workflow: upload a spreadsheet with location data (addresses, coordinates, or region names), choose how to visualize it, and style the result — no GIS software installation or coding required for the basics. It sits between a static chart tool and full desktop GIS software like QGIS: more mapping power than a chart, less complexity than a full spatial analysis pipeline.

Choosing the Right Map Type

Choropleth

Colors regions (districts, divisions) by a value — best for comparing a quantity across administrative areas.

Point Map

Plots individual locations — best for showing exactly where specific things are (incidents, facilities, monitoring stations).

Heat Map

Shows density or concentration across space — best when the pattern of clustering matters more than any single point.

Publishing and Embedding

Once built, a Carto map generates a shareable link and an embed code — a snippet you can drop directly into a web story's HTML, the same way you'd embed a YouTube video. This is what makes web mapping tools genuinely practical for daily publishing, versus a static map image that has to be re-exported every time the underlying data updates.

Don't Over-Interact

An interactive map with too many toggles and filters can bury the actual finding under options the reader has to figure out themselves. Default the map to the view that makes your point, and add interactivity only where it genuinely helps the reader explore further.

"The map should make its point before the reader touches anything. Interactivity is for exploring further, not for finding the story."
