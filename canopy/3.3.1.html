Loading and Layering Shapefiles

What a Layer Is

Each shapefile or GeoJSON you load becomes a separate layer — a district boundary layer, a river layer, a points-of-interest layer — stacked and toggled independently.

Coordinate Reference Systems

Every layer has a coordinate system. Mismatched systems between layers cause them to appear misaligned — QGIS can reproject on the fly, but it's worth confirming your layers actually share a system.

Simple Spatial Joins

A spatial join attaches attribute data from one layer to another based on their geographic relationship — the classic example is joining a set of points (say, reported pollution incidents) to the district polygon each point falls inside, so you can then count or summarize incidents by district.

Don't Publish Someone Else's Uncredited Boundaries

Administrative boundary data usually comes with a required attribution or license — check the source's terms before publishing a map built on it, the same way you'd credit a photograph.

Field Tool

Real Boundary Data Sources

For actual reporting and publication, use real, authoritative boundary and river data from these sources.

HDX — Bangladesh Subnational Boundaries ↗
Official administrative boundaries (division/district/upazila) sourced from the Bangladesh Bureau of Statistics, freely downloadable as shapefiles.
GADM ↗
Global administrative area boundaries by country, free for academic and non-commercial use.
geoBoundaries ↗
Open-license global administrative boundary database, actively maintained since 2017.
HydroSHEDS ↗
A widely used global river network and watershed dataset, useful for river-layer data beyond what administrative sources provide.
