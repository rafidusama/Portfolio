Field Craft

The map or chart that helped you find the story is rarely the one that should run with it. The analysis version is built to explore; the publication version is built to make one point clearly to someone who has never seen the data before.

The Handoff Between Analysis and Design

Analysis Version

Dense with detail, every available layer visible, built for you to explore and find the pattern — not meant for a general reader.

Publication Version

Simplified to the single finding that matters, with everything else stripped away or moved to a caption — built for someone seeing it for the first time, for a few seconds.

Simplifying for a General Audience

A technical map built for analysis often has layer names, coordinate grids, and jargon labels that mean nothing to a reader. Before publishing, ask what a reader with zero context needs to understand the point — usually far less than what you needed to find it.

Captioning and Sourcing Correctly

Every published chart or map needs, at minimum, what it shows, where the underlying data came from, and when that data is current as of. A map without a source citation is unverifiable to a reader — and to a future fact-checker, including possibly you.

"If a reader has to ask 'where did this come from,' the caption already failed."
